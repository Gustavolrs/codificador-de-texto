# **Decodificador de Texto 🛠️🔐**  
Este é um projeto interativo de Decodificador de Texto desenvolvido com **HTML**, **CSS** e **JavaScript**. Ele permite criptografar e descriptografar mensagens com base em regras específicas de substituição de letras, garantindo uma experiência intuitiva e prática.  

---

## **✨ Funcionalidades**  
- 🔒 **Criptografar Texto:** Converta as letras de um texto em suas criptografias correspondentes usando um conjunto de regras predefinidas.  
- 🔓 **Descriptografar Texto:** Restaure o texto criptografado ao seu formato original.  
- 📋 **Copiar Texto:** Copie o texto descriptografado para a área de transferência com um único clique.  
- ✅ **Validação de Entrada:** Aceita apenas letras minúsculas, sem acentos ou caracteres especiais.  

---

## **🧩 Regras de Criptografia**  
A criptografia é realizada substituindo as seguintes letras:  
- `e` → `enter`  
- `i` → `imes`  
- `a` → `ai`  
- `o` → `ober`  
- `u` → `ufat`  

---

## **🛠️ Tecnologias Utilizadas**  
- 🖼️ **HTML:** Estruturação da página e dos elementos.  
- 🎨 **CSS:** Estilização visual e responsividade.  
- 🧑‍💻 **JavaScript:** Lógica de criptografia e descriptografia, manipulação do DOM e validação dos dados de entrada.  

---

## **🚀 Como Usar**  
1. ✍️ Insira o texto que deseja criptografar ou descriptografar no campo de entrada.  
2. 🔒 Clique em **"Criptografar"** para converter o texto ou em 🔓 **"Descriptografar"** para restaurar o formato original.  
3. 📋 Utilize o botão **"Copiar"** para transferir o texto descriptografado para a área de transferência.
